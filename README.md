## `03` Featured Project

<div align="center">

### 🏃‍♂️ SmartCoach AI
**AI-Driven Athlete Performance Monitoring & Injury Prevention** — *Graduation Project*

</div>

An end-to-end system that monitors athlete movement and physiological signals to track performance and flag potentially incorrect movement patterns — fusing computer vision, wearable sensor data, and deep learning into one pipeline.

**Core components:**
- 🎥 **Computer Vision** — Real-time pose estimation with MediaPipe for biomechanical movement analysis
- 📡 **Sensor Fusion** — EMG signals + ESP32 microcontroller + Fitbit wearable data
- 🧠 **Deep Learning Pipeline** — GRU, LSTM, BiLSTM, BiGRU, and TCN models combined via a soft-voting ensemble for time-series prediction
- 🛠️ **Full-Stack Delivery** — FastAPI backend, PostgreSQL database, Streamlit dashboard, and a Flutter mobile app
